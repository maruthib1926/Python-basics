# SDLC and STLC

## What is SDLC?
SDLC stands for Software Development Life Cycle.

It is a process used to develop software.

## SDLC Phases

1. Requirement Analysis
2. Planning
3. Design
4. Development
5. Testing
6. Deployment
7. Maintenance

## What is STLC?
STLC stands for Software Testing Life Cycle.

It is a process followed by testers to test software.

## STLC Phases

1. Requirement Analysis
2. Test Planning
3. Test Case Development
4. Test Environment Setup
5. Test Execution
6. Test Cycle Closure

## Difference Between SDLC and STLC

| SDLC | STLC |
|---|---|
| Software Development Life Cycle | Software Testing Life Cycle |
| Focuses on software development | Focuses on software testing |
| Used by development teams | Used by testing teams |
