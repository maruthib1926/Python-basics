# API Testing

## What is API Testing?
API Testing is a type of software testing used to check whether APIs work correctly.

## Tool Used
Postman

## HTTP Methods

1. GET - Retrieve data
2. POST - Create new data
3. PUT - Update existing data
4. DELETE - Delete data

## API Testing Scenarios

| Test ID | Test Scenario | Expected Result |
|---|---|---|
| API01 | Send GET request | Data should be displayed |
| API02 | Send POST request | New data should be created |
| API03 | Send PUT request | Data should be updated |
| API04 | Send DELETE request | Data should be deleted |

## Status Codes

- 200 - OK
- 201 - Created
- 400 - Bad Request
- 401 - Unauthorized
- 404 - Not Found
- 500 - Internal Server Error
