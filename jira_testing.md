# Jira Testing

## What is Jira?
Jira is a tool used by software teams to track bugs, tasks, and project work.

## Bug Life Cycle

1. New
2. Assigned
3. Open
4. In Progress
5. Fixed
6. Retest
7. Closed

## Bug Report Fields

- Bug ID
- Bug Title
- Description
- Steps to Reproduce
- Expected Result
- Actual Result
- Severity
- Priority
- Environment
- Status

## Example Bug

### Bug ID
BUG-001

### Bug Title
Empty Employee ID Validation Failure

### Severity
Medium

### Priority
High

### Status
Closed

## Testing Process

1. Tester finds a bug.
2. Tester creates a bug report.
3. Developer fixes the bug.
4. Tester retests the bug.
5. If fixed, bug is closed.
6. If not fixed, bug is reopened.
